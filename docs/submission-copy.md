## Long description (100–150 words)

Built fast with Cursor, Claude Code, Lovable, v0, Bolt, or Replit? LegacyDoc
AI helps you understand and prepare what you shipped before cleanup,
refactor, or handoff. It runs inside VS Code on your local codebase,
generating documentation, Mermaid architecture maps, module summaries, areas
to inspect, and AI-ready context packs you can share with Claude Code,
Cursor, or Codex. Bring your own API key (BYOK). Your code is sent directly
to the AI provider you configure, never to RomantiCode servers. Free with 5
generations per day. Pro is a one-time $29 unlock for unlimited generations,
project-level analysis, and custom prompt templates. Works with JavaScript,
TypeScript, Python, and most other languages via your AI provider.

## Do-not-say (binding copy rules)

Do not write:

- "your code never leaves your machine"
- "local-only"
- "runs entirely on your machine"
- "complete security audit"
- "guarantee production ready"
- "automatically fix all AI-generated code"
- "replace senior engineers"
- "one-click vibe code cleanup"
- "upload your code for instant scanning"

These either conflict with actual product behavior (your code goes to your
AI provider) or overpromise what the tool does (it does not auto-fix or
certify production readiness).

Do write:

- "Runs inside VS Code + BYOK. No code storage or proxying by RomantiCode."
- "Audit-ready context pack"
- "Cleanup readiness report"
- "Architecture map"
- "Areas to inspect"
- "Cleanup priorities"
- "Refactor prep notes"
- "AI-ready review notes"
