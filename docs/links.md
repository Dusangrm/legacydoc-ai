## Rules for external use

  `www.romanticode.com`.
- Always use trailing slash for page URLs. Non-slash URLs 308-redirect to the
  slash version. Static assets (`robots.txt`, `sitemap-*.xml`, `favicon.svg`,
  `images/*`) must stay slash-free.
- Do not use shortened URLs in public submissions — submit the canonical
  trailing-slash URL directly.
